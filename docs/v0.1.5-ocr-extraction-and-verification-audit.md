# Justice Tax Solutions v0.1.5 OCR / extraction / verification audit

## Purpose

This build advances the platform from document classification to a conservative extraction-and-verification workflow. The product principle is:

**Extract and suggest; never file, sign, respond, or advise from extracted data until it is verified.**

## Added capabilities

- Local text extraction for text-like uploads.
- Starter PDF text extraction for PDFs with embedded text.
- OCR-required flag for image PDFs, photos, scans, and binary files.
- Confidence score and confidence label on each document extraction.
- Sensitive-value masking in extracted text previews.
- Source-linked extracted field candidates for common tax-problem and return documents.
- Field-level verification status.
- Client/staff/professional verification endpoint.
- Staff document classification endpoint.
- Staff document verification queue.
- Public diagnostics for extraction controls.
- PostgreSQL schema expansion for extraction jobs, extracted fields, and verification history.

## Fields flagged for verification

High-risk fields include:

- tax year
- response deadline
- notice/letter number
- amount due
- taxpayer ID patterns
- EIN/TIN
- W-2 wages and withholding
- nonemployee compensation
- 1099-K gross amount
- health-insurance marketplace numbers
- AGI/prior-return values

## Why this is safer than pure AI/OCR filling

Tax competitors increasingly use document upload, scan/import, and extraction, but taxes are high-risk. This build avoids claiming final automation. It produces a source-linked field plan and verification queue so staff and professionals can review facts before any return filing, notice response, payment plan, or tax-resolution advice.
