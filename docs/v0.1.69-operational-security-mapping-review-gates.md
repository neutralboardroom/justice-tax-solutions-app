# Justice Tax Solutions v0.1.69
## Operational, Security, Mapping, Review and Controlled Paid-Use Gates

This release does not falsely mark all captured IRS PDFs as live-ready. It adds the enforceable code and evidence structure required to approve forms one at a time for controlled paid preparation.

## Added

- Automated AcroForm field inventory for the captured IRS tax-debt form library.
- Per-form, per-language, per-revision release gates.
- 100% semantic mapping requirement before controlled paid use.
- Required sample-output hash and named visual-QA, professional, and owner approvers.
- Production security readiness dependency.
- Paid-pilot case creation that fails closed when any gate is missing.
- Internal Official Form Release Center page.
- APIs for field inventory, gate recording, release status, and paid-pilot eligibility.

## Hard boundary

A ZIP cannot by itself complete external production controls. Managed PostgreSQL, private object storage, malware scanning, authenticated email, MFA/access controls, backup/restore testing, WISP/retention/incident-response approval, verified professional credentials, Stripe live webhooks, and owner approval must be configured and evidenced in the live environment.

IRS e-file or agency submission remains disabled. Controlled paid use means guided preparation and print-ready output for a specifically approved form only.
