# v0.1.31 Official IRS Form 9465 PDF Capture + Visual Field QA Audit

## Goal

Move IRS Form 9465 from logical AI-first completion planning toward a controlled official-PDF QA workflow without enabling unsafe final client output.

## Added

- `src/form9465VisualQa.js`
- Official IRS Form 9465 capture profile.
- Source seeding endpoint for Form 9465.
- PDF capture readiness endpoint.
- Captured-PDF inspection endpoint for basic PDF/AcroForm signals.
- Page-zone visual QA map for both pages.
- Overlay-coordinate draft candidates for the first visual QA pass.
- Visual sample QA endpoint.
- Internal visual QA packet PDF endpoint.
- Staff visual QA board and QA status records.

## Guardrails

The build does not mark Form 9465 client-output-ready. Final official output remains blocked until:

1. Official IRS PDF is captured or attached.
2. SHA-256 checksum is recorded.
3. Page count/layout is confirmed.
4. Exact AcroForm fields or overlay coordinates are locked.
5. Sample-filled outputs are visually inspected.
6. Overflow, checkbox placement, dates, money fields, and signature areas are checked.
7. Client verification sheet is complete.
8. Required professional/reviewer release is recorded.
