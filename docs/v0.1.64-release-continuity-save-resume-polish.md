# Justice Tax Solutions v0.1.64 - Release continuity, save/resume polish, and homepage-stable platform refinement

This build does not add new IRS form bundles and does not redesign the homepage. It keeps the current homepage layout stable while strengthening the rest of the platform around deployment-safe persistence, customer/staff/professional save-resume continuity, quote/payment preservation, and release QA.

## Main rule

Every deployment must be treated as a source-code update only. It must not erase or reset customer accounts, login details, cases, saved work, uploaded document records, quotes, payments, staff notes, accountant/CPA/EA/professional work, release gates, or audit logs.
