# Justice Tax Solutions v0.1.12 — live paying-user gap audit and launch gate

This pass answers the founder question: what still needs to improve before live paying users, and what can be improved now inside the platform?

## Main finding

The platform now has strong product foundations: tax-problem-first intake, customer-friendly language, referrals/QR/flyers, professional review flow, encrypted local uploads, document extraction/verification scaffolding, official form ZIP ingestion, staff boards, and release gates.

The remaining risk is not a lack of features. The remaining risk is **production operating readiness**: database, private storage, malware scanning, live payments/webhooks, email delivery, verified professionals, written security plan, and official form mapping QA.

## What v0.1.12 improves now

1. Separates internal demo, private pilot, controlled paid pilot, and public launch.
2. Makes it explicit when sensitive taxpayer uploads should remain blocked.
3. Adds a founder board with what can be done now versus what requires production configuration.
4. Adds a WISP/security-plan checklist so operational security becomes part of the app, not a separate memory.
5. Adds an email-template inventory before real transactional email is enabled.
6. Adds a staff pilot-case board endpoint for future private-pilot review.

## Live launch blockers that remain

- Managed PostgreSQL must be configured.
- Private object storage must be configured.
- Malware scanning must be configured.
- Live Stripe keys and webhook must be configured and tested.
- Real transactional email must be configured.
- Staff/professional approval and MFA must be finalized.
- Professionals must be credential-verified.
- Official IRS/NYS/NYC forms must be uploaded, source-verified, mapped, sample-filled, and QA checked.
- Written security plan must be completed and followed.

## Recommended safe next mode

Until the live gate passes, use the site for **internal demo** or **private pilot without sensitive uploads**. A controlled paid pilot can begin only after the database, private storage, malware scanning, live Stripe/webhooks, email delivery, verified professional roster, and written security plan are in place.
