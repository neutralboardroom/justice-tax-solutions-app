# v0.1.38 IRS 9465 Capture Completion + Coordinate Simulation Audit

## Purpose

This version makes the IRS Form 9465 official PDF capture/upload workflow more operational by adding capture-completion readiness, coordinate-lock simulation, staff approval-gate reporting, and an internal PDF packet for QA review.

## What changed

- Added `src/form9465CaptureCompletion.js`.
- Added capture/upload completion readiness checks.
- Added coordinate-lock simulation plan.
- Added simulation-only staff approval records.
- Added staff approval-gate report separating simulation from actual release gates.
- Added internal QA packet PDF generator.
- Added staff board/status endpoints.
- Updated static smoke checks and package version to 0.1.38.

## Guardrails

Simulation approval is not final release approval. The module keeps `client_output_allowed` false and continues to defer to the final release gate audit before any client IRS output can be considered.

## Remaining blockers

The actual official `f9465.pdf` still needs to be captured in deployment or uploaded through the fallback endpoint, visually coordinate-locked against the real PDF, and sample-tested before the form can move toward final client output.
