# v0.1.17 Official Government URL Capture Audit

## Goal

Begin official IRS/NYS/NYC PDF capture in a controlled way without requiring the owner to manually download and upload every form.

## What changed

- Added an official URL discovery guide that states the platform can find and maintain common IRS/NYS/NYC official source URLs itself.
- Added a URL capture guide explaining why capture is intentionally disabled by default and how to enable it with `ALLOW_OFFICIAL_FORM_URL_CAPTURE=true`.
- Added an admin capture endpoint for seeded/registered source records: `POST /api/admin/official-form-sources/:id/capture-pdf`.
- Added dry-run support so staff can validate the official URL and review the capture plan before storing a PDF.
- Added PDF capture logic that validates official government HTTPS domains, fetches the PDF, checks size/type, saves the exact captured PDF, records SHA-256 checksum, links it to the source record, and keeps client output blocked.
- Updated the Official Forms page to show source IDs, capture status, capture mode, and a dry-run capture form.

## Safety gates preserved

- Source records alone cannot drive client output.
- Captured PDFs cannot drive client output.
- Field extraction, mapping, sample-fill testing, and qualified staff/professional verification are still required.
- Live sensitive taxpayer uploads remain blocked unless the separate production gates are configured.

## Recommended next version

v0.1.18 should add first-form field extraction against captured PDFs, starting with IRS 9465, IRS 2848, IRS 8821, IRS 433-F, and IRS 1040-X. Keep every generated form blocked until sample-fill QA and professional verification are complete.
