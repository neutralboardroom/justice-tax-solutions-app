# Justice Tax Solutions v0.1.23 Calendar Scheduling Integration Audit

## Purpose

Add calendar and scheduling integration readiness for live online, phone, and possible in-person tax professional sessions. The platform now supports a manual-first appointment workflow while preparing for future integrations with Google Calendar, Calendly, Microsoft Outlook/Microsoft 365, Microsoft Teams, Zoom, phone calls, and in-person appointments.

## What changed

- Added `src/calendarIntegrations.js`.
- Added provider-agnostic calendar/meeting policy.
- Added professional calendar configuration records.
- Added appointment scheduling event records.
- Added customer appointment-options and scheduling-preference endpoints.
- Added staff calendar config and appointment scheduling board endpoints.
- Added professional-session schedule update endpoint for staff-entered meeting links, booking links, phone instructions, and in-person locations.
- Updated live consultation, pricing, staff, README, and environment documentation.

## Guardrails

- Manual scheduling and staff-pasted links work first.
- The app does not claim real-time sync unless configured and tested.
- Customers should not see private professional calendars.
- Staff must still confirm quote/payment/scope before paid professional time is confirmed.
- Live sensitive taxpayer document and official-form release gates remain unchanged.

## Future integrations

Future versions can add OAuth/API sync for Google Calendar, Calendly webhooks/API, Microsoft Graph/Teams scheduling, and Zoom meeting generation after privacy, security, audit log, and reminder rules are finalized.
