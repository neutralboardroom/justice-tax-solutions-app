# Justice Tax Solutions v0.1.59 - Full-platform UX and customer-facing language polish audit

v0.1.59 is a full-platform refinement pass. It does not add a new IRS form bundle. It audits and improves the public user journey, dashboard, staff workbench, pricing/help/FAQ language, Spanish touchpoints, navigation clarity, and safe copy boundaries while preserving the existing controlled-launch posture.

## Primary goals

- Make the homepage and start flow easier to understand for personal filing, business filing, prior-return review/amendment screening, free Truth Check, and tax-problem users.
- Keep prior-return review prominent without guaranteeing refunds, savings, or amendment results.
- Reduce user confusion about what is free, what is paid, what is not live, and what requires professional review.
- Improve staff triage language and dashboard guidance.
- Add a full-platform polish audit page and API set.
- Fix small HTML/version-label issues found during the audit.

## Still blocked

Live sensitive uploads, final official IRS/NYS/NYC form output, e-file, agency submission, direct debit, Refund Transfer, refund advances, and guaranteed outcomes remain blocked/not live.
