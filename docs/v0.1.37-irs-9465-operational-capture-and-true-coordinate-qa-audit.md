# Justice Tax Solutions v0.1.37 — IRS Form 9465 Operational Capture Test + True Coordinate QA Workflow

## Purpose

v0.1.37 adds an operational QA layer for the first real IRS Form 9465 output path. Earlier versions created official source seeding, upload fallback, coordinate-lock planning, official sample preview, client verification, professional release, and final release audit gates. This pass makes those pieces more practical by adding a repeatable operational test and true-coordinate QA workflow.

## Guardrails

A passed operational QA event does not make Form 9465 client-ready. The official PDF must still be captured/uploaded, checksummed, inspected, coordinate-locked, visually compared, overflow-checked, signature/date blank checked, direct-debit handling checked, client verified, professionally released, paid/cleared where applicable, and production-security approved before final output.

## Packaging

The clean ZIP must exclude `node_modules`, `.env`, runtime data, uploaded/captured taxpayer documents, captured official PDFs, storage uploads, logs, and temporary files.
