# v0.1.33 IRS Form 9465 Upload Fallback + Coordinate Lock Audit

## Purpose

v0.1.33 makes the IRS Form 9465 official PDF workflow more operationally practical. Prior versions could seed the official source, attempt URL capture, draft field/overlay candidates, and generate internal sample overlay PDFs. This version adds a staff/admin fallback for situations where server-side URL capture fails or is intentionally disabled.

## Added

- Official IRS Form 9465 upload fallback with required attestations.
- PDF header validation and checksum calculation.
- Source URL validation requiring an IRS URL.
- Official form source linkage.
- Coordinate lock checklist and board.
- Coordinate lock status recording.
- Coordinate lock internal PDF packet generation.
- Final output gate report.

## New endpoints

- `GET /api/tax/forms/9465/capture-upload-fallback-plan`
- `GET /api/tax/forms/9465/coordinate-lock-checklist`
- `GET /api/tax/forms/9465/final-output-gate-report`
- `POST /api/admin/forms/9465/upload-official-pdf`
- `GET /api/staff/forms/9465/coordinate-lock-board`
- `POST /api/staff/forms/9465/coordinate-lock-status`
- `GET /api/staff/forms/9465/coordinate-lock-packet`

## Guardrails

- Upload fallback is staff/admin only.
- Upload fallback requires official-source, unmodified-PDF, and mapping-only attestations.
- Uploaded/captured official PDFs are not client-output-ready.
- Coordinate locks are QA records, not release approval.
- Final output remains blocked until official PDF, checksum, coordinate lock, sample output, visual QA, overflow QA, signature blank check, direct-debit confirmation/blank check, client value verification, professional release, and production gates all pass.
