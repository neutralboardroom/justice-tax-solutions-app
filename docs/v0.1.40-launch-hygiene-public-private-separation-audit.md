# Justice Tax Solutions v0.1.40 — Launch Hygiene + Public/Staff Separation Audit

## Purpose

v0.1.40 is a cleanup and launch-control polish pass. It does not add broad new product scope. It makes the latest v0.1.39 public-launch audit easier to trust as the next build base by aligning version markers, fixing package hygiene, tightening pilot readiness logic, and clarifying what belongs on public pages versus staff/internal pages.

## Preserved

- Tax-problem-first Justice Tax Solutions positioning.
- Public launch audit, launch action plan, user-value polish, conversion checklist, and staff launch control room.
- Private pilot release controls.
- Production security and sensitive-upload gates.
- Official IRS/NYS/NYC source, mapping, and output-readiness workflows.
- IRS Form 9465 controlled QA path, including upload fallback, coordinate-lock planning, visual QA, sample output, client verification, professional release, and final release audit.
- Pricing/review levels, quote/payment readiness, professional session readiness, appointment options, marketing pages, staff cockpit, and analytics.

## Changes made

1. Updated `package.json`, `package-lock.json`, `src/storage.js`, and smoke tests to version `0.1.40`.

3. Added `.gitignore` to keep future ZIP/Git deployments from accidentally including secrets, uploads, logs, dependency folders, runtime data, or captured PDFs.
4. Fixed private-pilot launch audit logic so invite readiness requires core secrets: JWT secret, admin token, staff signup code, and document encryption key.
5. Added `GET /api/platform/version-packaging-audit`.
6. Added `GET /api/platform/staff-public-separation-audit`.
7. Added version/package hygiene and public/staff separation sections to the launch audit UI.
8. Updated the public launch audit page title and endpoint list.
9. Updated the private pilot page label and removed a duplicate Launch Audit nav link.
10. Kept real sensitive taxpayer document uploads blocked by default.
11. Kept final official IRS/NYS/NYC form output blocked by default.

## Launch interpretation after v0.1.40

The public site may be reviewed and limited no-sensitive private pilot planning may continue when deployment, SSL/domain, core secrets, safe upload gates, and owner/staff instructions are configured.

The platform is still not ready for:

- live sensitive taxpayer documents;
- final official IRS/NYS/NYC client form output;
- e-file or agency-submission claims;
- guaranteed tax relief claims;
- broad paid marketing that implies live secure document handling or final filing capability;
- unverified professional review.
