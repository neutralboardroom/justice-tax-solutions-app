# Justice Tax Solutions v0.1.74

Adopts the selected **Logo Concept 2** as the official Justice Tax Solutions logo system.

## Goals

- Preserve the existing color palette and typography.
- Replace the old shield/scale logo family.
- Standardize a document-and-checkmark logo family for website, favicon/app icons, and referral-flyer marketing output.
- Keep the platform's existing flow and layout intact.

## What changed

- Replaced `public/logo.svg` with a horizontal Justice Tax Solutions wordmark using the selected document/check icon.
- Replaced `public/brand-mark.svg` with the selected transparent document/check icon for website headers.
- Replaced `public/favicon.svg`, `public/favicon-32.png`, `public/apple-touch-icon.png`, and `public/icon-512.png` with the new icon family.
- Added `public/email-logo.png` and `public/marketing-logo.png` as reusable raster logo assets.
- Updated the referral-flyer PDF generator to use the new marketing logo image instead of the prior text-only top header.
- Updated the internal brand-system page to reflect the selected logo family.

## Preserved

- Existing colors.
- Existing fonts.
- Existing site structure and routes.
- Existing homepage/start flow.
- Existing form engines, release gates, and sensitive-upload restrictions.
- Existing fail-closed language around filing, signatures, e-file, and professional approval.
