# Justice Tax Solutions v0.1.24 Production Security + Sensitive Upload Readiness Audit

## Purpose

v0.1.24 hardens the production security and sensitive-upload readiness layer before real taxpayer documents, paid marketing, or print-ready official form output are offered to public users.

## Added

- New `src/productionSecurity.js` module.
- Sensitive taxpayer data classification matrix.
- WISP/security go-live checklist.
- Access-control audit for staff, professionals, pending approval, MFA/equivalent control, and professional scope.
- Security launch blockers and safe marketing mode.
- Staff checklist endpoint for recording security-control status.
- Production configuration page rendering for security controls, access blockers, sensitive data classes, and live-sensitive-upload blockers.
- Additional environment flags for WISP, retention, incident response, backup/restore, professional verification, official form output approval, and security go-live approval.

## Upload gate hardening

`buildSensitiveUploadPolicy()` now requires the production security approvals before `accept_live_sensitive_documents` can become true. Configuration of storage and malware scanning alone is not enough.

Required before live sensitive upload mode:

- `LIVE_PAYING_USERS_ENABLED=true`
- `ALLOW_SENSITIVE_DOCUMENT_UPLOADS=true`
- managed database / `DATABASE_URL`
- strong `DOCUMENT_ENCRYPTION_KEY`
- private object storage
- malware scanning
- staff/professional MFA or equivalent control
- staff approval required
- `WISP_APPROVED=true`
- `DATA_RETENTION_POLICY_APPROVED=true`
- `INCIDENT_RESPONSE_PLAN_APPROVED=true`
- `BACKUP_RESTORE_TESTED=true`
- `SECURITY_GO_LIVE_APPROVED=true`

## Current safe launch posture

The platform can continue supporting internal demos, private no-sensitive pilots, redacted/sample testing, referral demonstrations, appointment workflows, pricing exploration, and AI-first form-planning demos.

It should not be marketed as accepting real sensitive taxpayer documents or releasing print-ready official forms until production security, professional, payment, and official form-output gates are complete.

## Regression focus

- Existing redacted/sample upload path must remain available when acknowledged.
- Existing blocked live-sensitive upload path must remain blocked when gates are incomplete.
- Existing referral, pricing, professional-session, calendar, official-form, AI-interview, staff, and dashboard foundations must remain intact.
