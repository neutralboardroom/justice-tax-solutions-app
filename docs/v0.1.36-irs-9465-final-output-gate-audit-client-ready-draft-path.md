# v0.1.36 IRS Form 9465 Final Output Gate Audit + Client-Ready Draft Path

This version adds the final audit layer before any IRS Form 9465 client-ready print/signature draft can be released.

## Added

- `src/form9465FinalRelease.js`
- Final release policy endpoint.
- Final output gate audit endpoint.
- Client-ready draft path endpoint.
- Controlled audit packet PDF generator.
- Case-level final gate audit and draft path endpoints.
- Staff final release board and final release audit status recording.

## Gate policy

Final client IRS output must remain blocked unless these gates pass:

1. Official IRS Form 9465 PDF captured/uploaded.
2. SHA-256 checksum recorded.
3. Official source URL recorded/validated.
4. Coordinates or AcroForm fields locked.
5. Official-sample visual comparison generated and reviewed.
6. Page 1 and Page 2 visual comparison passed.
7. Overflow/formatting review passed.
8. Signature/date fields verified blank.
9. Direct debit fields confirmed-or-blank.
10. Client values verified.
11. Professional release/signoff recorded.
12. Payment/quote clearance verified where applicable.
13. Production security clearance passed.
14. Staff final release audit recorded.

## Output status

The new packet generator is an audit/review packet by default. It should not be treated as final IRS output unless the final gate audit explicitly reports `final_client_irs_output_allowed: true`.

## Remaining blocker

The actual official IRS `f9465.pdf` still needs to be captured in deployment or uploaded through the fallback endpoint, visually coordinate-locked, and sample-tested against the real official PDF.
