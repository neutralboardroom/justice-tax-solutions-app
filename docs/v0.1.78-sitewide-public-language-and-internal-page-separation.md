# Justice Tax Solutions v0.1.78

## Scope
A sitewide customer-language audit and public/private page separation pass.

## Public changes
- Removed visible version numbers, pilot/build terminology, release notes, QA terminology, mapping terminology, and operational instructions from public pages.
- Replaced them with plain explanations of what customers can do, what review is needed, and what is not guaranteed.
- Removed visible “Language” and “Language / Idioma” labels while retaining the icon, English / Español controls, keyboard access, and screen-reader label.
- Rebuilt `official-forms.html` as a customer-facing tax form help page.

## Internal protection
Operational, owner, staff, deployment, QA, PDF-intake, release, and readiness pages now require an authenticated staff-capable account before static delivery. They also send no-index directives. The original official-form administration interface is preserved at `official-forms-admin.html` behind the same protection.

## Preservation rule
No form engine, customer workflow, API, staff tool, account flow, responsive layout, payment path, or data model was intentionally removed.
