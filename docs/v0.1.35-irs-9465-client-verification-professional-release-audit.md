# v0.1.35 IRS Form 9465 client verification and professional release audit

## Purpose

This version adds the release-control layer needed before a Form 9465 print/signature draft can be prepared for a client. The intent is to reduce human work where safe, but still require explicit client verification and required professional release before any client-facing packet is generated.

## Added

- `src/form9465ClientRelease.js`
- Client verification policy/checklist for IRS Form 9465.
- Case-level client verification records.
- Professional release gate and status records.
- Print/signature draft readiness report.
- Controlled print/signature draft packet PDF generator.
- Staff release-gate board.
- Official Forms dashboard panel for v0.1.35 gates.

## Guardrails

- Final client IRS Form 9465 output remains blocked.
- The print/signature packet is a controlled review packet, not a final filing copy.
- Signature/date fields must remain blank for client signing after review.
- Direct-debit routing/account fields require explicit client confirmation or must remain blank.
- Government-only areas must remain blank.
- No IRS acceptance, installment agreement approval, deadline, relief, refund, or agency outcome is guaranteed.

## Gate logic

The release gate checks:

1. Client values verified.
2. Professional assigned where required/requested.
3. Professional release recorded.
4. Official IRS PDF captured or uploaded.
5. SHA-256 checksum recorded.
6. Coordinates locked.
7. Fill-engine readiness.
8. Official sample output QA.
9. Production security/payment/release gates.

Only the controlled print/signature review packet can be considered after the client/professional gate passes. Final official IRS output still requires all gates.
