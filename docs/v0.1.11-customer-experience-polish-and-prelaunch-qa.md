# Justice Tax Solutions v0.1.11 — customer experience polish and pre-launch QA

## Goal

This pass focused on making the platform easier and more credible for real customers. The prior versions built the tax-problem engine, professional review workflow, referrals, QR/flyers, document extraction foundation, official form ingestion readiness, and live-readiness gates. v0.1.11 improves the customer-facing layer so ordinary users can understand the next step without tax jargon.

## Improvements made

- Refined logo, brand mark, favicon, PNG favicon, Apple touch icon, 512px app icon, and web manifest.
- Added `src/customerExperience.js` with customer-language rules, simple start options, dashboard copy, simple case status, customer-experience report, and pre-launch quality checklist.
- Added `/api/platform/customer-experience`.
- Added `/api/platform/prelaunch-quality-checklist`.
- Added `/api/cases/:id/simple-status`.
- Added `/customer-experience.html` internal UX QA page.
- Improved homepage hero copy so it starts with the tax problem instead of forms.
- Added a short four-step customer flow: start free, get organized, choose review, move carefully.
- Improved dashboard copy and case-card language.
- Added a “Plain status” action so customers can see a simple summary of where the case stands.
- Improved mobile/header CSS so navigation is more compact and readable.
- Tightened action buttons and card layout for small screens.
- Updated brand-system rules and asset list.

## Key UX rules locked into the platform

- Use plain words before tax jargon.
- Show the next step clearly.
- Keep free starting help separate from paid human review.
- Avoid any promise of refund, settlement, penalty removal, payment plan approval, offer-in-compromise acceptance, audit result, or government decision.
- Flag urgent issues calmly and tell the user what to do next.
- Show what is missing and what has been received before asking for paid review.
- Keep header/hero typography compact on mobile.
- Do not use official-looking government branding.
