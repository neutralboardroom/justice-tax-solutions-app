# Justice Tax Solutions v0.1.77

Adds a prominent, accessible English/Español selector at the top of every HTML page and a responsive navigation/mobile/tablet polish pass.

## Changes

- Sitewide top language bar with English and Español choices.
- Spanish selection routes to the Spanish public help hub and preserves a safe return path to the originating English page.
- Homepage language query preselects Español in the intake form.
- Legacy one-off language links in page navigation are hidden when the unified selector is active.
- Mobile navigation uses an accessible Menu/Close control with large touch targets.
- Tablet navigation wraps into a usable second row rather than overflowing.
- Tables receive keyboard-accessible horizontal scrolling on small screens.
- Inputs, buttons, cards, headings, and footer spacing receive phone-size refinements.
- Every public HTML page loads the shared behavior script.

## Preserved

- Approved logo, colors, and typography.
- Existing public routes and core customer flows.
- Spanish-language public pages.
- Existing staff/owner pages and operational functions.
- Sensitive-upload restrictions, official-form release gates, and no-guarantee language.
