# v0.1.54 IRS 843/9423/12153 Appeals and Abatement Bundle

## Purpose

This build adds a controlled, no-sensitive public organizer and logical official field map for:

- IRS Form 843 — Claim for Refund and Request for Abatement
- IRS Form 9423 — Collection Appeal Request
- IRS Form 12153 — Request for a Collection Due Process or Equivalent Hearing

The bundle is tax-problem-first: penalty abatement, refund/abatement claims, liens, levies, installment agreement appeals, CDP notices, and equivalent-hearing triage.

## Safety posture

This is not final IRS output. It is an organizer, mapping, staff checklist, sample QA, and professional-review trigger layer.

Blocked:

- final official PDF output
- full SSN/ITIN/EIN collection in public mode
- taxpayer/preparer/representative signatures
- IRS mail/fax/upload/submission claims
- appeal representation claims
- deadline guarantees
- penalty-removal or collection-hold guarantees

## Important review triggers

Escalate to staff/professional review for:

- levy, seizure, garnishment, lien, CDP, LT11, CP90, CP504, Letter 1058, or revenue officer language
- Trust Fund Recovery Penalty / IRC 6672 / payroll tax issues
- bankruptcy discharge issues
- innocent spouse issues
- collection alternative requests involving Form 433-A/433-B financial disclosure
- uncertain CAP/CDP deadline or routing
- any request involving actual sensitive tax documents or official filing output
