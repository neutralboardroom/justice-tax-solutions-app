# Justice Tax Solutions v0.1.30 — Private Pilot Release Candidate audit

## Purpose

v0.1.30 turns the platform into a controlled private-pilot release candidate. It does not make the platform public-launch ready, and it does not enable live sensitive taxpayer uploads, final official form output, e-file, or broad paid marketing by default.

## Release-candidate behavior

The private pilot gate separates these stages:

1. no-sensitive invite-only private pilot;
2. controlled paid pilot with staff/professional review;
3. live sensitive taxpayer document handling;
4. broad public marketing and public launch.

The build intentionally says broad public marketing and live sensitive uploads are not recommended yet.

## Safety gates preserved

- Sensitive taxpayer uploads remain blocked unless production security gates are approved.
- Official IRS/NYS/NYC form output remains gated behind source capture, checksum, field mapping, sample-fill QA, overflow/signature checks, client verification, and required professional review.
- Emails/messages must not contain sensitive taxpayer details.
- No e-file claim is made unless an EFIN/e-file provider or partner path is configured.
- Justice Tax Solutions remains not the IRS, not New York State, not NYC, and not a law firm.

## Pilot scenario matrix

v0.1.30 adds sample pilot paths for:

- IRS notice help with redacted/sample notice;
- tax debt / IRS Form 9465 installment agreement path;
- unfiled or prior-year returns;
- amended return / Form 1040-X concern;
- self-employed/gig-worker Schedule C help;
- customer-requested reassurance review;
- referral/community partner start.

## Remaining blockers

The platform is still not ready for broad public live launch or real sensitive taxpayer-document handling until managed PostgreSQL, private object storage, malware scanning, staff/professional access controls or MFA, WISP, retention/deletion, incident response, backup/restore, verified professional operations, live Stripe webhooks, transactional email, and final operating procedures are configured and tested.
