# Justice Tax Solutions v0.1.8 — Live Paying User Audit and Polish

## Purpose
This pass audits the prior v0.1.0–v0.1.7 foundation against what would be needed before serving real paying tax users. The core conclusion is that the product direction is strong, but the platform must explicitly gate live use around client acknowledgments, professional review, secure storage, payments, and operating procedures.

## What was already strong
- Tax-problem-first positioning with return help included.
- Referral program with codes, tracked links, QR images, and flyers.
- Account, dashboard, staff workbench, review queue, release gates, and referral ledgers.
- Multi-AI vendor structure with cautious rule fallback.
- Encrypted local document storage and access logging.
- Official form ZIP ingestion and mapping queue readiness.
- Document classification, extraction suggestions, and verification workflow.

## Production gaps found
- Intake accepted cases without explicit client acknowledgments recorded as structured data.
- Paid review requests could be triggered before a client-readiness blocker check.
- The site needed a visible live-readiness page so owner/staff do not confuse a deployable test app with production tax-document readiness.
- Staff needed a single operations endpoint to see blocked cases and launch blockers.
- The homepage needed more live-facing trust language and fewer version-note phrases.

## Live launch rule
Do not accept live sensitive tax documents or paid final review/release cases until the required readiness checks pass: managed database, strong secrets, dedicated document encryption key, private object storage, malware scanning, Stripe live webhook, email delivery, staff approval, and at least one verified professional/preparer in the roster.

## Remaining pre-production items
- Activate a real PostgreSQL adapter instead of JSON-local adapter.
- Configure private object storage and malware scanning.
- Configure email provider and account verification flows.
- Configure live Stripe keys/webhooks.
- Add MFA for staff/admin users.
- Add real professional onboarding/credential verification SOPs.
- Upload official IRS/NYS/NYC form ZIPs and complete field mapping QA.
- Add real OCR/document-AI provider or keep manual-verification-only mode visible.
- Complete taxpayer engagement/authorization documents for each service tier.
