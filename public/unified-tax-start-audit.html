Unified start audit

Unified start flow + filing/review/amendment prominence.

This internal/public-review page checks whether the platform clearly supports personal filing, business filing, past-return/amendment review, free Truth Check, and tax-problem help without adding fake production claims.

Public acceptance checks

  • File a Personal Tax Return is visible on homepage, navigation, and intake.
  • File a Business Tax Return is visible and not buried under gig-worker language.
  • Review Past Returns / Amendment Check is a major homepage feature.
  • Free Tax Problem Truth Check is clear and not behind a payment gate.
  • Paid filing, amendment preparation, response preparation, bookkeeping cleanup, tax resolution, and professional review start only if the user chooses deeper help.

Audit endpoints

GET /api/platform/public-start-map
GET /api/platform/unified-start-readiness-audit
POST /api/tax/personal-filing-readiness
POST /api/tax/business-filing-readiness
POST /api/tax/prior-year-amendment-opportunity
POST /api/tax/free-truth-check-summary

What remains blocked

No final filing, official form output, e-file, Refund Transfer, refund advance, live sensitive uploads, agency submission, direct debit, or professional-review claim becomes live from this UX build.

Language guardrails

Use “appears to be,” “may involve,” “may be worth reviewing,” and “verify deadlines/options.” Do not use guaranteed settlement, guaranteed refund, IRS impersonation, fake CPA/EA/attorney status, or fake e-file language.
